# KNK TEX — Техническое задание

## Роль

Ты — Senior Product Designer, UX/UI Designer и Senior Full Stack Developer.

Твоя задача — разработать современный корпоративный сайт-каталог для компании **KNK TEX**, занимающейся оптовой продажей портьерных тканей.

Перед написанием кода тщательно продумай архитектуру проекта, структуру компонентов, навигацию, UX и SEO.

Не усложняй проект ненужным функционалом. Главная цель сайта — представить ассортимент компании и мотивировать клиента оставить заявку или связаться с менеджером.

---

# О компании

Компания занимается продажей **портьерных тканей**.

Важно понимать особенности продукции.

Это НЕ магазин трикотажа.

На фотографиях должны использоваться:

- рулоны портьерных тканей;
- спокойные оттенки;
- дорогой интерьерный стиль;
- современный склад;
- рулоны шириной около 70 см;
- никаких ярких разноцветных тканей.

Сайт должен вызывать ощущение надежного поставщика тканей.

---

# Целевая аудитория

- швейные производства;
- дизайнеры интерьеров;
- салоны штор;
- оптовые покупатели.

Розничные продажи компанию не интересуют.

---

# Цель сайта

Сайт НЕ является интернет-магазином.

Через сайт нельзя оформить заказ.

Сайт нужен для:

- просмотра ассортимента;
- ознакомления с характеристиками тканей;
- просмотра ориентировочной стоимости;
- получения контактной информации;
- отправки заявки на обратный звонок.

После этого менеджер связывается с клиентом самостоятельно.

---

# Минимальный заказ

Минимальный объем заказа:

**от 50 метров ткани.**

Это необходимо указать в нескольких местах сайта.

---

# Стек

Использовать:

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

Проект должен быть полностью адаптивным.

---

# Структура сайта

Сайт состоит из следующих страниц.

## 1. Главная

Содержит:

- Hero-блок;
- логотип;
- краткое описание компании;
- преимущества;
- категории тканей;
- блок доставки;
- форму обратной связи;
- контакты.

Не использовать:

- новости;
- статьи;
- акции;
- лидеров продаж;
- отзывы.

---

## 2. Каталог тканей

Основной раздел сайта.

Необходимо предусмотреть:

- поиск;
- фильтрацию;
- карточки товаров.

Фильтры:

- категория;
- производство;
- плотность;
- ширина полотна;
- цена;
- цвет.

Поиск должен быть простым и быстрым.

Без сложного интеллектуального поиска.

---

## 3. Карточка ткани

Каждая ткань должна содержать:

- название;
- фотографию;
- категорию;
- ширину полотна;
- плотность;
- страну производства;
- количество цветов;
- базовую стоимость в USD;
- автоматически рассчитанную стоимость в рублях.

Также должна быть кнопка:

> Оставить заявку

или

> Получить консультацию

После нажатия открывается форма обратной связи.

---

## 4. Доставка

Отдельная страница.

Использовать данные из предоставленного Excel-файла.

Не делать обычную скучную таблицу.

Оформить красиво в виде карточек либо современного расписания.

Отразить:

- транспортную компанию;
- дни отправки;
- направления.

---

## 5. Контакты

Страница должна содержать:

- телефон;
- Telegram;
- WhatsApp;
- электронную почту;
- реквизиты;
- режим работы;
- карту.

---

# Каталог

Для первоначального наполнения использовать предоставленный Excel-файл.

В дальнейшем данные будут обновляться вручную разработчиком.

Административная панель НЕ нужна.

CMS НЕ нужна.

Все данные могут храниться локально.

---

# Фотографии

На первом этапе допускается использование заглушек.

Позже фотографии будут постепенно заменяться на реальные.

Важно предусмотреть возможность простой замены изображений.

---

# Стоимость

Стоимость каждой ткани хранится в долларах США.

На сайте отображается:

Цена:

350 $

≈ 27 500 ₽

Стоимость в рублях должна автоматически рассчитываться по официальному курсу Центрального Банка РФ.

Курс обновляется автоматически.

---

# Остатки

Не показывать.

Никаких:

- "В наличии";
- "Заканчивается";
- "Под заказ".

---

# Калькулятор

В карточке ткани предусмотреть простой калькулятор.

Покупатель вводит количество метров.

Сайт показывает ориентировочную стоимость.

Калькулятор не оформляет заказ.

Он нужен только для понимания бюджета.

---

# SEO

Сайт должен сразу проектироваться с учетом SEO.

Продумать:

- корректную структуру URL;
- title;
- description;
- Open Graph;
- sitemap;
- robots.txt;
- Schema.org;
- хлебные крошки;
- семантическую разметку;
- оптимизацию изображений;
- высокую производительность.

---

# Дизайн

Стиль:

- современный;
- минималистичный;
- дорогой;
- премиальный;
- чистый.

Без перегруженности.

Использовать большое количество свободного пространства.

Карточки товаров должны выглядеть современно.

Не использовать устаревшие решения.

---

# Цветовая гамма

Использовать фирменный логотип KNK TEX как основу.

Основные цвета:

- графитовый;
- темно-серый;

- плавное появление блоков;

- аккуратные переходы.

Без чрезмерной анимации.

Сайт должен одинаково хорошо работать:

- на телефонах;
- планшетах;
- ноутбуках;
- больших мониторах.

Мобильная версия должна проектироваться не после, а одновременно с десктопной.
